💻 Códigos e Consultas

A mesma pergunta, "quanto foi gasto em cada categoria?", respondida em três linguagens:

SQL

Em estudo 
SELECT categoria, SUM(valor) AS total
FROM despesas
GROUP BY categoria
ORDER BY total DESC;

Python

Em estudo • 72h 
import pandas as pd

df = pd.read_csv("despesas.csv")
(df.groupby("categoria")["valor"]
   .sum()
   .sort_values(ascending=False))

R

Prática Avançada 
library(dplyr)

despesas |>
  group_by(categoria) |>
  summarise(total = sum(valor)) |>
  arrange(desc(total))
