Linguagens que estudo e pratico

A mesma pergunta, "quanto foi gasto em cada categoria?", respondida em três linguagens. Os códigos são exemplos ilustrativos.

SQL

Em estudo

Consultas para buscar, filtrar e resumir dados em bancos relacionais.

SELECT categoria, SUM(valor) AS total
FROM despesas
GROUP BY categoria
ORDER BY total DESC;

Python

Em estudo, curso de 72h

Análise e tratamento de dados com pandas, voltado a finanças.

import pandas as pd

df = pd.read_csv("despesas.csv")
(df.groupby("categoria")["valor"]
   .sum()
   .sort_values(ascending=False))

R

Conhecimento e prática

Análise e visualização de dados, com relatórios que misturam texto, código e gráficos.

library(dplyr)

despesas |>
  group_by(categoria) |>
  summarise(total = sum(valor)) |>
  arrange(desc(total))
